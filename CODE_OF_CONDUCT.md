# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep criticism about the code, not the person. Harassment, insults and personal attacks are not tolerated in issues, pull requests, discussions or any other project space.

## Reporting

If someone's behavior makes you uncomfortable, report it privately to the maintainers through the repository's **Security** tab (**Report a vulnerability**), and mention that it is a conduct report. Reports are kept confidential.

The maintainers may remove comments, close threads, or ban contributors who break this code, as described in the Contributor Covenant's enforcement guidelines.
